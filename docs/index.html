Real Linux

Not a simulation. The same tools you use at your desk.

TermFold unpacks a genuine Debian root filesystem and runs it with PRoot, so compilers, package managers and full-screen terminal apps behave normally.

  • No root and no special setup. Install the APK and open it.
  • Your projects live in Linux, so symlinks, permissions and git are correct.
  • Agents install themselves the first time you type their command.

Release notes

Questions

Good to know.

Do I need root?

No. TermFold runs Debian in user space with PRoot, as an ordinary Android app. Nothing about your device is modified.

Does it work on a phone?

Yes, the layout adapts. It shines on a tablet with a keyboard, where the chat, files and terminal sit side by side.

How is this different from Termux?

Termux is a great terminal. TermFold is built around coding with AI agents: a bundled Debian that stays consistent, a native chat for agents, a browser they can drive, a file manager and an editor, with the setup done for you.

Which agents work?

Anything that runs on Linux and Node. Claude Code, Codex, Gemini CLI, OpenCode, Cursor, Pi and Qwen Code install on first use, and several get a native chat through the Agent Client Protocol. You bring your own account or API key for each.

Why isn't it on Google Play or F-Droid?

Google Play requires a newer target Android version than TermFold can use while still running Linux binaries from its own storage. F-Droid requires every binary to be built from source, and TermFold ships PRoot built by the Termux project. Releases here are signed APKs, and the app can update itself.

Is it safe to install an APK from GitHub?

Each release lists a SHA-256 checksum, the source is public under Apache-2.0, and the in-app updater verifies both the checksum and the signing key before handing a file to Android.

How much space does it need?

About 100 MB to unpack, plus the developer tools (a few hundred MB), plus whatever you install. Plan on a few GB free.
